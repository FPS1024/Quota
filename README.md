# Quota

Quota is a minimal SwiftUI app for checking API balances and organization usage across multiple AI providers.

## Supported providers

- DeepSeek
- Kimi / Moonshot
- OpenRouter
- xAI
- OpenAI
- Anthropic
- Qwen
- Google Gemini

Provider credentials are stored in the iOS Keychain. Providers must be configured and enabled in Settings before they appear on the Usage page.

## Requirements

- Xcode 15 or newer
- iOS 15.6 or newer

Open `Quota.xcodeproj` in Xcode and run the `Quota` scheme.
